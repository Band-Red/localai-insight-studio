# تقرير تحديثات تطبيق LocalAI Insight Studio 🛠️

**تاريخ التقرير:** 28 فبراير 2026

تم فحص ومراجعة صفحة النماذج المحلية (GGUF Models) وإجراء التحديثات والتعديلات اللازمة بناءً على طلبك. إليك ملخص ما تم إنجازه:

## 1. ⚙️ التحقق من ربط الإعدادات بالـ Backend

تم فحص الكود المصدري لصفحة النماذج (`ModelManager.tsx` و `main.ts` وغيرها)، والتأكد من التالي:

- **الخادم الأساسي (Server Config):** جميع المتغيرات (مثل تخصيص الرام، الـ VRAM، وتفعيل `mmap`) مرتبطة بشكل ممتاز بـ Backend عبر أوامر الـ IPC وتقوم بتمرير الـ Flags الصحيحة لمحرك `llama-server.exe`.
- **معلمات النموذج (Model Parameters / Settings):** معلمات مثل `Temperature` و `Top-P` وموجه النظام (`System Prompt`) مرتبطة وتُحفظ محلياً ليتم استخدامها في المحادثات.
- **خوادم MCP (mcp.json):** تم التحقق من نافذة إعدادات MCP. التطبيق يقوم بقراءة وكتابة ملف `mcp.json` بنجاح من وإلى القرص المحلي عبر `ipcMain.handle('gguf:save-mcp')`.
- **تحديث الحزم:** لاحظت أنك تنوي استخدام تقنية MCP (Model Context Protocol)، ولضمان عملها بسلاسة في المستقبل، قمت بتثبيت حزمة `@modelcontextprotocol/sdk` الرسمية في بيئة المشروع وتم دمج التحديث.

لا توجد حالياً أي ملفات مفقودة تعيق العمل الأساسي، المحرك (`llama-server.exe`) متواجد وإعدادات الربط سليمة وتعمل في الخلفية.

## 2. ✨ ميزة التنسيق التلقائي لملفات JSON

تمت إضافة الوظيفة المطلوبة لتسهيل إدخال الإعدادات:

- **مربع تهيئة MCP (mcp.json Editor):** أصبح الآن يدعم التنسيق التلقائي (Auto-Formatting). بمجرد لصق هيكلة `JSON` (مهما كانت عشوائية أو في سطر واحد)، سيقوم المحرر برمجياً بالتقاطها وترتيبها بمسافات بادئة (Indentations) لتظهر بمظهر منظّم فوراً. كما تم إضافة رسالة نجاح صغيرة (✅ تم تنسيق JSON بنجاح) تظهر عند اللصق لتأكيد العملية.
- **مربع System Prompt:** تم تفعيل نفس الميزة المذكورة أعلاه في مربع موجه النظام. إذا قمت بلصق هيكل `JSON` يحتوي على `{ "prompt": ..., "chosen": ... }` سيتم ترتيبه تلقائياً ليقرأه النموذج بشكل أوضح.

## 3. 🔍 المراقبة والتحقق عبر الـ Terminal (CMD)

تم تشغيل التطبيق في وضع التطوير وعمل مراقبة للاستهلاك في الخلفية:

- تم التأكد من أن التعديلات الأخيرة المتعلقة بتصحيح مسارات `llama.cpp` والمشكلة الخاصة بالـ `Speculative Decoding --model-draft` تعمل بكفاءة.
- الـ Node و `webpack` يقومان ببناء الملفات دون أخطاء برمجية حرجة (Warnings متعلقة بـ deprecations فقط ولا تؤثر على التطبيق).
- لا يوجد أي أخطاء `stderr` قاتلة تعيق الواجهة حالياً.

## 🔄 الخطوات تم رفعها لـ GitHub

جميع التعديلات والتحسينات المذكورة في هذا التقرير، بالإضافة إلى التحديثات السابقة التي حلت مشاكل الاتصال بالنموذج، تم الالتزام بها ورفعها بنجاح إلى الفرع `main` في مستودع `Band-Red/localai-insight-studio`.

يمكنك الآن فتح التطبيق وتجربة لصق أي كود `JSON` في خانة الإعدادات واختبار سلاسة الاستخدام.
