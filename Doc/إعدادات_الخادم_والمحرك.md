# إعدادات وتشغيل النموذج المحلي (GGUF) 🚀

بناءً على طلبك ونوع البيانات أو الـ System Prompt الذي تفضل استخدامه (خاص بالبرمجة والمقارنة بين الإجابات الصحيحة والخاطئة)، قمت بتجهيز أفضل إعدادات ممكنة لضمان دقة عالية من النموذج ومنعه من "الهلوسة" (Hallucination) عند كتابة الأكواد.

---

## 1. ⚙️ إعدادات الخادم (Server Configuration)

هذه الإعدادات تحدد كيف يستهلك النموذج موارد جهازك (RAM و GPU) للحصول على أسرع استجابة:

- **طول السياق (Context Length):** `4096` أو `8192` (حسب حجم الذاكرة لديك، 4096 كافية جداً للأكواد القصيرة والمتوسطة).
- **طبقات كرت الشاشة (GPU Layers):** `35` (إذا كان لديك كرت شاشة منفصل، ارفع الرقم للحد الأقصى لكي يقوم بنقل الحمل من المعالج إلى كرت الشاشة، مما يضاعف السرعة).
- **حجم الدفعة (Eval Batch Size):** `512` (رقم قياسي وممتاز لمعالجة النصوص).
- **استخدام mmap (Use mmap):** `مفعل (ON)` لزيادة سرعة قراءة النموذج من القرص.
- **إبقاء النموذج في الذاكرة (Keep in Memory / mlock):** `مفعل (ON)` إذا كان لديك رامات (RAM) بحجم 16GB أو أكثر ليمنع إعادة تحميل الملف من القرص.

---

## 2. 🎛️ إعدادات التوليد (Generation Settings)

بما أنك تستخدم النموذج في البرمجة والمقارنة المنطقية دقيقة، يجب جعل النموذج أكثر "صرامة" وتركيزاً، وتقليل فرصة الإبداع العشوائي:

- **درجة الحرارة (Temperature):** `0.2` إلى `0.3` (مهم جداً للبرمجة أن يكون الرقم منخفضاً لتكون الإجابات دقيقة ومباشرة).
- **Top-K:** `40`
- **Top-P:** `0.85` أو `0.9`
- **عقوبة التكرار (Repeat Penalty):** `1.15` (لمنع النموذج من تكرار نفس الأسطر البرمجية بشكل لا نهائي).

---

## 3. 🤖 موجه النظام (System Prompt)

استناداً إلى مثالك الذي يحتوي على `prompt`, `chosen`, و `rejected`، يُفضل توجيه النموذج ليتبع دائماً أسلوب الشرح الواضح مع إعطاء الإجابة الصحيحة الصافية وتوضيح سبب رفض الأوامر الأخرى. اكتب هذا في إعدادات النظام للنموذج:

\`\`\`text
أنت مساعد برمجي خبير وذكي.
عندما يسألك المستخدم عن كيفية أداء مهمة برمجية، يجب عليك:

1. إعطاء الأمر البرمجي الصحيح (Chosen) بشكل مباشر ومختصر.
2. استخدام لغة ومصطلحات البايثون (أو اللغة المطلوبة) بدقة.
3. إذا لزم الأمر، حذر المستخدم من استخدام أوامر شائعة وخاطئة (Rejected) مع توضيح سبب الخطأ باختصار.
   التزم دائماً بالدقة العالية وتجنب الأكواد الزائدة.
   \`\`\`

---

## 4. 🔌 إعدادات بروتوكول السياق (MCP Configuration)

ملف إعدادات الـ MCP (الذي يمكنك لصقه في نافذة تحرير MCP داخل إعدادات التطبيق) مجهز هنا ليسمح للنموذج باستدعاء أدوات أو تخصيص الردود مستقبلاً برمجياً.

\`\`\`json
{
"mcpServers": {
"python_assistant": {
"command": "python",
"args": ["-m", "interpreter"],
"enabled": true,
"description": "خادم مخصص لتحليل وتجربة الأكواد بشكل محلي للتحقق من الـ Chosen والـ Rejected",
"settings": {
"strict_mode": true,
"max_execution_time": 10
}
}
}
}
\`\`\`

### 💡 خطوة أخيرة للتجربة داخل التطبيق:

1. اذهب إلى نافذة **(النماذج / GGUF)** 🧠 في التطبيق.
2. قم بتعديل المُنزلقات (Sliders) لتطابق الأرقام في قسم (1).
3. اضغط على زر **تشغيل النموذج (Load Model)**.
4. اذهب لنافذة الدردشة، ولاحظ كيف سيتبع تعليمات الـ System Prompt بشكل ذكي ودقيق جداً!
